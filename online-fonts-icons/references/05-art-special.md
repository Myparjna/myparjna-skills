- **font-family**: `zihunbiantaoti`
- **风格**: 扁平现代字体，字形偏矮宽，笔画末端带圆弧收尾，整体轻微右倾
- **来源**: ZeoSeven (已替换原 chinese-fonts-cdn)
- **原址**: https://fonts.zeoseven.com/items/405/

### CDN

```html

```

```css

```
