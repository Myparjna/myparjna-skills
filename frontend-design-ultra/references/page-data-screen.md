# 数据大屏专项流程

适用：监控指挥中心、值班室、展厅的固定分辨率大屏（常见 1920×1080），1–3 米观看距离，常无人值守，以轮播与实时刷新为主。属 Operate 的变体：成功标准是**远观可读、状态一目了然、异常抢眼**。

**以远观扫读为主时，关键信息直接可见，不依赖点击或悬停。有人值守并需要处理任务时，结合工作台流程提供操作。大屏不等于地图、视频或深色科技风。**

## 设计流程（按序执行）

1. **观看场景确认**：观看距离、是否有人操作、是否需要轮播。决定字号基准与信息节奏。
2. **信息分区**：按首先需要判断的业务问题分配空间。定位/分布/路径任务且有位置数据时用地图，查看现场或影像证据时用视频，有明确三维任务才用3D。纯运营屏可完全由指标、趋势、对比、进度和异常列表组成；不规定中央媒体区或固定面积占比。
3. **固定画布网格**：目标确为固定分辨率时使用固定栅格或必要的绝对定位；按信息优先级排布，不强制中间主图加左右列。交互式宽屏工作台按容器重排。模块宽高与间隙按 `alignment-grid.md` 的画布网格模数取值（全屏边距与模块间隙各一档），KPI 行卡片等宽等高、数字与标签对齐方式全行统一。
4. **缩放策略**：非原生视口展示时，用 `transform: scale()` 适配，缩放比 = min(可用宽/画布宽, 可用高/画布高)，**宽高同时计算取小值**，居中放置；禁止拉伸视频、地图、图表的宽高比。
5. **状态与告警设计**：有告警任务时显示等级、时间戳和来源；状态用文字/图标配合颜色。只有内容溢出且允许轮播时启用，提供暂停；无告警任务不凭空生成告警队列。刷新失败保留旧数据并标注时效与失败状态。
6. **动效克制**：必要刷新给局部反馈，不默认地图呼吸、数字滚动或常动元素；告警注意力表达服务于等级和时效，尊重减少动效偏好。在线、连接正常、设备存活这类状态用静态色形文字表达，不加循环闪烁或呼吸的点；告警脉冲光环属可接受的注意力动效，但需提供关闭入口。

## 布局模式库

| 场景与适用条件 | 候选结构 |
|---|---|
| 空间分布/调度：位置是核心问题，有位置数据 | 地图 + 地域汇总 + 异常列表，区域比例按任务决定 |
| 视频监看：需要查看现场画面或证据 | 常见比例视频区/视频网格 + 点位状态 + 相关事件 |
| 告警中心：重点是发现和处理异常 | 告警队列 + 等级/趋势汇总 + 按需详情；定位或查看证据需要时才加地图/视频 |
| 纯生产运营：产量、效率、质量、进度比较 | 关键指标 + 趋势/对比 + 进度/异常明细，无需媒体区域 |
| 无异常或记录不足 | 保持业务结构并显示相应状态，不用地图或装饰图填空 |

## 质量底线

- 展示型大屏总标题默认相对整个画布居中，左侧放品牌或场景，右侧放时间和必要操作；可用等宽左右栏的三列网格，避免两侧内容长短让标题偏移。长标题与操作冲突时调整字号、换行或分层，不覆盖。用户或现有项目指定布局时沿用。各模块标题仍按自身内容轴对齐，无需全部居中；不因此添加巨型 Hero 或装饰标题框。
- 远观或无人值守场景的关键信息不可依赖悬停；有人操作的次要帮助才采用 `progressive-help.md`。
- 关键指标数字 ≥32px，标题 ≥20px，正文 ≥14px（按 2 米视距）；数字等宽。
- 主题默认深色底（弱光环境与远观可读性的业务惯例），浅色项目体系或用户明确要求时沿用；正文与实际背景对比度 ≥4.5:1，关键控件 ≥3:1，状态不只靠颜色表达。
- 视频按 `media-ratios.md` 使用常见比例并保留源画面；地图/图表按容器重新布局，不拉伸内容。仅实际使用的瓦片/图链需要加载失败回退。
- 地图链路按无人值守场景设计可靠性：瓦片源选免 Key 且已验证稳定的来源并锁库版本；加载中提示在任一瓦片成功后立即撤销，失败判定依据明确错误（瓦片 `onerror`、库未加载），不用固定短超时把网络慢判成失败（大屏同时拉字体、视频封面、瓦片与脚本，冷缓存下整页可能十几秒）；确有失败时保留可点重试入口，地图失败不影响其余模块继续显示；非首屏必需的资源延后加载。
- 模块数量由任务、字号和视距决定，必要时分组；不按7±2机械裁掉关键信息。轮播不能让关键异常长时间不可见。
- 汇总数字与分项必须能对上账；百分比标注基数与时间范围。
- 缩放后左右留白接受为正常；不许为了填满而拉伸内容。

## 本形态反模式

- 视频、地图被拉伸变形（历史测评最高频硬伤）；
- 把桌面工作台的密集表格搬上大屏，远观一片模糊；
- 无意义科技风装饰：粒子流、扫描线、发光边框全套——抢走数据的注意力；
- 关键告警依赖 hover 才显示详情；
- 没有空间或影像任务仍放中央地图、视频、3D；
- 每块面板各用一套配色，主次和状态语义不一致。
