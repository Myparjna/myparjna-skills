# 对齐与栅格系统（Alignment & Grid）

对齐是页面秩序的来源，靠"感觉"必然失准。本文件把对齐与栅格定为可测量的工程规则：写代码前先定轴，写完后用坐标验证。适用于全部页面形态；形态差异见文末。

**违反本文件的间距、轴线、栅格值按 A 级质量缺陷处理，发现即修复，不归入审美偏好。**

---

## 1. 基准网格：一切尺寸取刻度

- 所有尺寸——宽、高、间距、圆角、图标大小、边框偏移——一律取 **4 的倍数**（4/8/12/16/24/32/48/64）；密排行内元素允许 2。
- 13、17、22、26 这类任意值禁止出现在布局样式里；来自既有项目体系的值原样沿用，不为了刻度改线上产品。
- 圆角也走刻度（4/8/12/16），全页只允许一档主圆角 + 一档小圆角。
- 图标视觉尺寸统一（16/20/24），不出现 18 与 22 混用。

## 2. 对齐轴：先定轴，后排元素

**规则：同一视野内的元素，必须能归到少数几条共享轴上；轴数量越少，页面越有序。**

- **左轴（最重要）**：页头/导航、标签页（Tab）、筛选器、内容卡片、表格首列、页脚——左边缘共享同一 x 坐标，由容器统一的水平内边距（如 24px）决定。Tab 和分段控件（红箭头式错位最常发生处）：Tab 组的左缘 = 内容区左缘，不是悬空的。
- **卡片内部**：卡片标题、正文、操作按钮从同一卡片内边距（如 16/20px）起排；卡片之间内边距统一一档。
- **右轴**：数字列、金额、计数右对齐并共享右轴；操作按钮组贴卡片右内边距。
- **标题跟随内容轴**：模块标题与该模块内容左对齐；不把小标题孤立居中（大屏总标题除外，见其形态条款）。
- **基线**：同行文字、图标+文字组合按文字基线对齐，不按顶边凑。
- **禁止**：为了"视觉平衡"单独挪动某元素的边距；元素一律贴轴，不贴轴的先改结构。

## 3. 桌面工作台：栅格系统

- 核心要求：必须用 CSS Grid 栅格，列数不限死——8、12、16、24 均可，按内容密度与信息优先级选（密度高选多列、密度低选少列）；选定列数后同页只用一档，不中途换。
- 列间距与模块间隙统一一档（如 16/24），同一页面只用一档页面左右边距。
- 卡片与区块用 `grid-column: span n` 跨列占格，不用 flex + `flex: 3` 这类比例凑数；常见主次结构用不等分跨列，均等三分用于真正同级的并列内容。
- 窄屏降级顺序事先规划：先收次要列，最终单列堆叠；降级后轴线仍保持一致（卡片全宽后左轴不变）。

## 4. 数据大屏：固定画布网格

- 基准画布 1920×1080（或目标分辨率），缩放比按 `min(可用宽/画布宽, 可用高/画布高)`。
- 模块布局在画布内用统一网格模数：先定边距（如 24）与模块间隙（如 16/24，全屏一档），剩余宽度按 `n = (画布宽 − 2×边距 − (列数−1)×gap) / 列数` 等分，模块宽高都落在网格模数上。
- KPI 行：卡片等宽等高，数字与标签对齐方式全行统一。
- 多列结构列宽按信息优先级分配（重要内容宽、次要内容窄），不均分占位导致某列内容挤压换行；列数与比例按内容定，不限固定配方。
- 大屏允许固定 `px` 值与必要绝对定位（画布本身固定），但模块之间仍走网格模数，不随手写 x=317 这类偏移。

## 5. 移动端 H5

- 4pt 基准照用；页面左右边距统一 16（≥360px 屏幕），列表卡片间距统一一档。
- 单列为主；确要并排（双列缩略图、操作组）用 `repeat(2, 1fr)` 等分，子元素内对齐规则不变。
- 安全区（刘海/手势条）内边距叠加后仍保持左右边距一致。

## 6. 表单对齐

- label 置于输入框上方左对齐；label 文字起点 = 输入框左缘。
- 同一表单内：输入框宽度统一（按栅格列，如全部 8 列宽），不出现参差；必填标记、后缀图标位置统一。
- 校验反馈与说明文字与输入框左轴对齐，就近显示。

## 7. 落地页

- 段落块（Hero、价值、证据、行动）共享中轴或左轴，选定一种贯穿全页。
- 栅格与工作台一致（12 列），但允许更大胆的跨列布局；跨列仍落在列上，不脱离栅格。

## 8. 验证方法（写完后必做）

1. **坐标抽查**：DevTools 选中页头、Tab、卡片、表格，读左边缘 x 坐标，同轴元素必须相等。
2. **网格覆盖**：浏览器缩放 100% 下目检列间隙是否等宽；或截图后叠加参考线核对。
3. **刻度扫描**：全局搜索样式值 `margin|padding|gap|width|height`，非 4 倍数且无既定体系依据的逐一归档修正。
4. **塌缩复验**：调窄窗口过断点，轴线与栅格列数按第 3 步规则切换，无元素脱轴。

## 9. 快速检查表

- [ ] 所有布局尺寸是 4 的倍数？
- [ ] 页头/Tab/筛选/卡片/表格左缘同一 x 坐标？
- [ ] Tab 组左缘与内容区对齐，无悬空错位？
- [ ] 卡片内边距全页一档？模块间隙全页一档？
- [ ] 栅格用 CSS Grid 列跨度（列数按内容定、同页一档），没有 flex 百分比凑数？
- [ ] 数字列右对齐 + 等宽数字？
- [ ] 断点切换后轴与列数按规则变化？
- [ ] 大屏模块宽高落在画布网格模数上？
