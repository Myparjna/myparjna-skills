# 反俗套分级清单

分两级使用：

- **A 级·质量硬禁令**：任何项目都必须遵守，违反即为缺陷，无豁免（除非用户明确要求）。
- **B 级·审美风险提示**：这些是 AI 生成的高频默认答案。不是永远错误，而是**未经思考不许使用**。使用时必须能回答"为什么这个页面需要它"，答不上就换方案；需求明确点名时直接用。

---

## A 级·质量硬禁令

**内容与数据**
- 禁止 lorem、占位灰块、"示例文本"；图片必须真实加载（图链 + `onerror` 兜底），且内容与业务语义贴合（管道告警配管道现场图，不贴切的主动换图）；同一对象的缩略图与详情图用同一图源。
- 禁止数据对不上账：汇总与分项一致、百分比有基数、趋势有时间范围；模拟数据保持业务可信度，不靠"加个小数点"伪装真实。
- 禁止假品牌（Acme/Nexus/SmartFlow）、假人名（John Doe）；业务语汇具体到点位、设备、算法级别。
- 禁止空话文案：赋能、抓手、闭环、Elevate、Seamless、Next-Gen。
- 禁止同一信息整页反复陈述：品牌/系统名显性出现至多两处（如导航 logo 一处、版权行一处），logo、主标题、版权三处讲同一个名字属冗余；主标题给名称、副标题给价值或范围说明，禁止换措辞重复标题；同一卖点或口号全页只出现一次，多个区块换说法重复同一句属冗余。

**交互与可用性**
- 禁止死按钮：页面上出现的每个控件都要有真实行为或明确状态。
- 禁止 emoji 充当图标；图标用矢量库，描边粗细全站统一。
- 禁止删除可见键盘焦点；禁止只靠颜色传达状态（配图标或文字）。
- 禁止任何视口出现横向意外滚动；全高移动页面按容器设计采用 `min-height:100dvh`（Tailwind `min-h-dvh` 或 `min-h-[100dvh]`）及正确滚动策略。
- 异步/可变模块不遗漏实际需要的加载、空态、错误及恢复路径；不为静态内容制造三态。

**排版与可读性**
- 禁止正文对比度 <4.5:1、关键控件 <3:1；灰色文字与灰色背景按实际对比度判断，不按颜色名称封禁。
- 视频画面采用 `media-ratios.md` 的常见比例，禁止随意扁长比例或拉伸变形；监控与证据画面不能为铺满而裁掉信息。
- 禁止装饰性字体用于正文、表格、表单标签。
- 禁止数字不用等宽（或 `tabular-nums`）出现在表格与指标里。

**动效**
- 禁止动画 `top/left/width/height`（只动 `transform`/`opacity`）。
- 禁止不尊重 `prefers-reduced-motion`。
- 禁止自定义鼠标指针。
- 禁止在线/存活/实时/连接正常这类状态用循环闪烁或跳动的点（色形文字静态表达即可）；禁止给严重度色条、卡片边框、标题等常驻元素加周期性明暗动画；循环动效只服务于加载与刷新过程，过程结束即停。
- 禁止用固定短超时把加载慢判定为失败；失败判定要依据明确错误（HTTP 错误、`onerror`、库未加载）。

## B 级·审美风险提示（用前必须给理由）

**配色**
| 模式 | 何时合理 |
|---|---|
| 米色底 + 衬线大字 + 赤陶橙点缀 | 生活方式、手作、食品品牌，且整体语言一致 |
| 近黑底 + 荧光绿/朱砂红单强调 | 极客工具、电竞、安全产品、监控大屏 |
| 紫蓝霓虹渐变 + 发光按钮 | 几乎不合理；游戏/元宇宙题材可局部用 |
| 纯黑 `#000000` | 按品牌、内容与对比度判断；不因反俗套自动替换成炭黑/锌灰；大屏默认深色，宜用深灰蓝等有层次的底色，慎用纯黑 |

**版式**
| 模式 | 何时合理 |
|---|---|
| 居中 Hero + 双按钮 | 单动作产品（搜索/下载/输入框）确实成立时；本条不限制大屏总标题居中，也不限制正常对话框或空状态对齐 |
| 三等分卡片功能行 | 内容确实同质并列且仅 3 项；多于 3 项考虑其他结构 |
| 全大写 eyebrow 小标签 | 编辑/时尚类页面，全站统一时 |
| 报纸细线 + 零圆角密栏 | 新闻、财经、数据密集阅读产品 |
| 单 word 斜体/变色强调标题 | 编辑类标题克制使用时 |
| `A · B · C` 中点串 / `词 — 碎片`标签 / 链接统一挂 `→` | 全站语言统一且克制时，不要每个页面元素都来一遍 |

**字体**
| 模式 | 何时合理 |
|---|---|
| Inter | 工具类产品配等宽数字时可用；追求性格时换 Geist/Satoshi/中文定制体 |
| 衬线体上仪表盘/后台 | 几乎不合理；编辑、文化、金融品牌官网可用 |
| 超大号 H1 | 视觉主导页面（活动页/作品集）；工作台与移动端收敛 |

**动效与装饰**
| 模式 | 何时合理 |
|---|---|
| 每区块 fade-and-slide-up | 落地页可用一次编排；工作台/大屏不用 |
| 每卡片 hover 上浮 | 电商/内容卡片可用；数据面板不用 |
| 辉光、扫光、粒子背景 | 游戏、活动页局部；其余删 |
| 全站玻璃拟态（backdrop-filter 毛玻璃） | 深色大屏面板分层可局部用；浅色工作台慎用，注意性能与对比度 |
| 渐变标题字 | 品牌主视觉一处；不蔓延到正文 |

## 使用方法

1. 设计计划完成后，先过 A 级清单——有违反直接改，不需要理由。
2. 再过 B 级清单——命中的每条写下保留理由（一句话），写不出就替换。
3. 构建完成后的截图验证里，对照本清单做最终确认。
