# 外部资源、视频与内容图

页面使用地图瓦片、外部图片、网页字体、CDN 脚本或视频时读取本文件。

## 加载判定

- 按网络真实耗时设计：只要有任一资源加载成功，即撤销“加载中/失败”提示并正常呈现。
- 失败判定依据明确错误：HTTP 错误、`onerror`、库未加载、确无任何资源返回。不用固定短超时把“慢”判定为“失败”。
- 等待时间应给足。同一页面常同时拉取字体、大图、瓦片与脚本，冷缓存下整页可能需要十几秒。
- 超时后保留可点击的重试入口；失败或未就绪的区域不阻塞其余内容展示。
- 地图瓦片优先采用免 Key 且已验证稳定的来源；需要 API Key 或来源不稳定的，不作为默认方案。
- 非首屏必需的外部资源延后加载，控制同期请求总量；不在一页堆叠多个同类 CDN 库；首屏图片压缩并懒加载。

## 视频净画面

- 正常播放时直接呈现源视频，不额外添加 LIVE、在线标记、红点、时钟、点位名称或装饰遮罩，也不把这些内容移到画面外重复显示。
- 无法播放时，在黑色画面区域内用空状态图标与必要的简短提示表达。
- 源视频或 MP4 自带的时间、点位、水印原样保留。
- 比例规则见 `media-ratios.md`。

## 内容图

- `pexels-media` 等取图技能可用时，优先用其获取与业务语义贴合的真实图片。
- 不可用时使用稳定图链，并统一添加 `onerror` 兜底。
- 不使用占位灰块，不使用与业务无关的通用图库图。
