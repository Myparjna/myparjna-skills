# 视频画面比例

适用于视频播放器、监控画面、告警视频证据和视频封面，各页面形态共用。

## 净画面

- 默认不在实际视频区域叠加前端生成的LIVE、在线/离线徽标、红点、日期时钟、点位名称、编号、水印或装饰渐变遮罩。多路轮询缩略画面同样遵守，悬停也不重新覆盖这些信息。
- 正常播放以视频画面本身呈现可用状态，不另外添加在线/离线标识、状态红点或跳动动画，也不在画面外补一套状态、时间和点位信息。视频流或MP4已经包含的时间、点位和水印直接保留；即使源没有这些信息，也不默认由前端补造时钟、水印或点位标签。
- 无视频源、连接失败或播放错误时，在原有比例的黑色画面区域内展示相应空状态图标与必要的短提示，按需提供重试；恢复播放后移除空状态。状态依据播放器事件或实际连接结果判断，不仅凭视频像素发黑判定离线，避免把夜间画面误判。加载、缓冲、正常暂停不误报为离线。
- 播放、暂停、全屏等必要操作优先放画面外工具栏；使用原生播放器时允许交互期间的原生控制条，不额外制作常驻覆盖条。无播放源时可在空区域显示错误与重试，恢复后移除。
- 原始视频中已经烧录的时间、标识属于源内容，不通过裁切、遮挡或修图去除。用户明确要求的字幕、告警分析框、证据标注按任务保留；不得以此为由默认给所有视频添加分析覆盖层。
- 检查正常播放、轮询缩略图、悬停、失败与恢复状态：没有前端额外覆盖文字、红点或遮罩，没有画面外重复信息；失败时黑屏空状态清楚，恢复后消失，视频比例始终保持。

## 常见比例

| 比例 | 常见用途 |
|---|---|
| 16:9 | 横向视频、常规监控、宽屏画面 |
| 4:3 | 原始源为4:3的摄像头或历史视频 |
| 1:1 | 方形视频内容或明确需要方形的视频封面 |
| 9:16 | 竖屏视频、手机拍摄内容 |

- 默认从这四种比例中按内容选择。禁止为填满卡片、挤进侧栏或凑齐高度随意制造窄条、超扁或其他奇怪比例。
- 优先匹配真实源比例。源或用户明确采用其他规范比例时保留并记录原因；不要为满足比例清单拉伸或裁掉真实证据。
- 用 `aspect-ratio` 或对应框架样式约束**实际画面区域**；标题、工具栏、播放器控件和说明位于区域外，不计入画面比例。
- 监控和证据画面优先 `object-fit: contain`，接受留白，完整保留信息；不使用 `fill` 拉伸。装饰封面可按内容用 `cover`，确认裁切不丢失主体；不要把封面的裁切方式套到证据播放器。
- 同组视频按源方向和用途组织，调整列数、卡片宽度或周边信息，不随窗口变化任意改变视频比例。
- 地图没有固定视频源比例：容器变化后让地图重新布局，保持瓦片与坐标正确；图表按容器重绘，避免CSS拉伸。不要把16:9强加给地图、图表或整块面板。

```css
.video-frame { aspect-ratio: 16 / 9; overflow: hidden; }
.video-frame > video,
.video-frame > img { width: 100%; height: 100%; object-fit: contain; display: block; }
```

验证桌面和目标手机宽度下的实际画面区域比例；播放器未加载时也保留区域尺寸。检查人脸、设备、字幕和告警框未变形或被裁掉，尤其检查侧栏、小卡片和竖屏内容。
