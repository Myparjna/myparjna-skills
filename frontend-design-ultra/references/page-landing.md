# 官网 / 落地页专项流程

适用：产品官网、活动页、发布页、定价页。属 Persuade 模式：访客的成功是**被打动并采取一个行动**（注册、购买、预约、下载）。

**与其他形态的根本差异：这是唯一允许"表达优先"的形态——但表达服务于一个明确的转化目标，不是自我陶醉。**

## 设计流程（按序执行）

1. **单一转化目标**：全页只服务一个主行动。写下它，之后每个区块都回答"这对促成该行动有什么帮助"，答不上来的删掉。
2. **受众与语汇**：写给谁看、他们关心什么。首屏文案用受众的语言说出价值，不用企业内部语汇。
3. **信息架构排序**：经典有效序列为 Hero（是什么）→ 价值点（为什么选你，3 个以内）→ 证据（案例/数据/评价）→ 行动（CTA）。可以变体，但"证据在行动之前"不能省。
4. **视觉世界建立**：从行业、产品材质、受众气质推导色板与字体——这是本形态与其他形态共用方向合同的地方。
5. **记忆点设计**：全页推荐一个记忆点（一种排版处理、一张主视觉、一个交互瞬间），其余区块克制服务。记忆点不能伤害加载与可读性。
6. **节奏控制**：区块疏密相间，信息密度低于工作台；滚动有叙事感但不依赖滚动劫持。

## 布局模式库

| 场景 | 推荐结构 |
|---|---|
| 产品发布页 | 左文右图（或右文左图）Hero + 三个价值点 + 截图展示 + 定价 + CTA |
| 活动报名页 | 主题主视觉 + 议程/亮点 + 嘉宾 + 报名表单（字段 ≤5） |
| 企业官网首页 | 品牌 Hero + 业务板块入口 + 案例数据 + 新闻/动态 + 页脚导航 |
| 下载/工具页 | 功能演示主视觉 + 特性对照 + 平台下载按钮组 |

## 质量底线

- 首屏在移动端也完整传达"这是什么 + 主按钮"，CTA 与背景对比度 ≥4.5:1。
- 首屏性能优先：主视觉图片压缩、字体 `font-display: swap`、不阻塞渲染。
- 文案具体：写"3 分钟生成巡检报告"，不写"赋能企业数字化转型"。数字标注统计标准（时间范围、样本）。
- 全站一个主 CTA 样式（颜色、圆角、文案结构），重复出现保持一致。
- 移动端导航折叠为汉堡菜单；区块在小屏塌回单列，图文不错位。
- 表单只收必要字段；提交有 loading、成功、失败三态。

## 本形态反模式

- 居中 Hero + 一句话 + 两个按钮的万能模板（用之前先问：这真是最适合本案的吗）；
- 假大空文案与假数据（99.99%、10 万+ 无出处）；
- 三个一模一样的圆角卡片排功能点，图标还是 emoji 或千篇一律的打勾；
- 每个区块 fade-and-slide-up，滚动劫持夺走用户的滚轮；
- 首屏堆 5 个同优先级按钮，访客不知道点哪个。
