# 常用交互

- 来源：https://developer.huawei.com/consumer/cn/doc/design-guides/hmi-scenes-0000001748650380
- 抓取时间：2026-04-04T08:23:44.511Z（2026-09-09 补抓子页面正文）

> 通用方法摘录：拖拽与框选的可视化反馈规则对 Web 桌面端同样适用；vp 按 px 概念对应。

## 拖拽

流程三阶段：发起拖拽 → 拖拽中 → 释放拖拽。

**发起拖拽**

- 触屏：先选中对象，长按浮起预览图（伴震动反馈），移动大于 10vp 发起；文本类对象先进入选中态才能拖拽，内容类对象长按直接发起；拖拽失败时原选中态保留。
- 鼠标：选中后按下移动即发起；误松手时原选中态保留。
- 发起后原对象灰显；对象较大时等比缩放避免遮挡页面（排序场景不缩放，跟手移动）。
- 多选拖出：多个对象聚拢成堆，右上角显示数量角标。

**拖拽中**

- 复制：原对象灰显；移动：原对象消失，宫格/列表控件有挤位动效。
- 鼠标按住 Ctrl 可将移动切换为复制；跨窗口拖拽通常为复制。
- 拖拽抵达页面边缘可触发滚屏；根据目标区域切换角标状态（移动/复制），不接收的区域呈禁止状态。
- 多指协同：拖拽过程中另一只手可以滚屏、切换应用。

**释放拖拽**

- 目标可接受时松手即落入对应位置；编辑输入区表现为插入缩略图。
- 目标不接受时预览图角标变为禁止：目标在可见范围内，抬手后对象归位原处；目标不可见（如跨窗口），原地放大淡出。
- 内容过多处理耗时时，对象用呼吸缩放动效缓解等待感，耗时过长需给出等待提示。

## 框选

- 发起：鼠标按下并移动发起，抬手完成。内容类对象（列表、宫格等容器）可从空白处发起并显示选框，热区大的对象可分区（空白区框选、图标标题区拖拽）；文本类对象无选框，呈现文本选中态，悬停时指针为工字形。
- 加减选（键鼠操作，支持触屏/触控板 + 键盘协同）：
  - Ctrl + 点选/框选：间序跳选；
  - Shift + 点选/框选：连续加减选；
  - Shift + 方向键：走焦加减选，从列表对应方向的末尾项开始加选。
- 视觉规则：选框 1vp 描边、半透明底板；文本选中用高亮底板色；选框与光标四个边缘各留 1vp。
