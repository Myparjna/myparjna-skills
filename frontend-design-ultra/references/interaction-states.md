# 任务状态与恢复

仅为实际任务设计状态。按“对象 → 触发 → 状态变化 → 界面反馈 → 恢复方式”记录并实现，不用统一成功提示代替业务操作。

| 情况 | 行为要求 |
|---|---|
| 首次没有记录 | 解释这里显示什么，并给创建/导入等适用入口 |
| 筛选无结果 | 保留条件，允许清除或修改，不误报成首次无数据 |
| 加载/刷新 | 在相关区域反馈；已有数据可保留并标明正在刷新 |
| 表单校验失败 | 标签和错误就近关联，说明修正方法，保留已输入内容 |
| 保存失败/断网 | 保留编辑，说明尚未保存，给重试；不假报成功或清空记录 |
| 提交中/重复点击 | 防止重复执行，不锁住无关功能；失败后恢复可操作状态 |
| 请求乱序/取消 | 旧请求不能覆盖新结果，取消后迟到响应不改变当前状态 |
| 删除/撤销 | 可逆低风险删除提供真实撤销，恢复对象、排序和计数；无恢复能力不显示撤销 |
| 不可逆/高影响动作 | 执行前说明对象、数量、后果和具体动作；不对所有删除/停用机械二次确认 |
| 返回列表 | 保留合理的筛选、分页、选择及滚动上下文 |
| 操作完成 | 列表、详情、汇总与数量从同一数据源联动更新 |
| 权限受限 | 说明限制与可执行路径，不伪装成无数据 |

普通成功用局部更新或轻提示；错误给原因和下一步。查看弹窗可点外部关闭，含未保存编辑时避免误触丢失。

弹窗焦点管理：打开时焦点移入弹窗内首个可操作元素，Tab 循环限制在弹窗内部不外逃；Esc 可关闭；关闭后焦点归还给触发弹窗的元素，不落在页面顶部或丢失。抽屉、半模态、下拉菜单同理。

验证实际点击、校验失败、保存/重试、删除/撤销及关联数量等相关路径。模拟故障入口放测试工具或开发模式，不作为正式页面常驻功能。没有后端的原型说明模拟范围，不声称真实提交或服务器持久化成功。
